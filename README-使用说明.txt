《欲望底色》手机互动测试使用说明

一、优先使用手机链接
购买后请优先使用卖家提供的手机链接，在微信、小红书或手机浏览器中直接打开即可开始测试。
推荐使用最新版 Chrome、Edge、Safari 或微信/小红书内置浏览器。

二、离线备份包
如果手机链接暂时无法打开，可解压“desire-bottom-color-offline.zip”，再双击文件夹内的 index.html。
离线版不需要登录、安装软件或联网；题目、计分、结果雷达图和分享文案都可正常使用。

三、使用提示
1. 全部 32 题为必答题，完成后可查看结果并复制分享文案。
2. 页面刷新后会尝试恢复本机的答题进度；如需重新开始，请在结果页点击“重新测试”。
3. 首屏视频会在设备允许时静音播放；网络较慢、省流模式或视频无法播放时，静态封面仍可正常使用，不影响开始测试。

四、内容边界
本作品仅供娱乐与自我观察，不构成心理诊断、医疗建议或专业评估。请勿将测试结果作为现实决策的唯一依据。
